Metric definitions

H-SR Success rate; H-Score Mean completion score (bottles: mean(k/6)).

NLDLJ ↓ ln(T³ ∫‖jerk‖²dt / peak_speed²), excluding differentiation stencils across plans; NSPARC ↓ Positive spectral arc length of speed magnitude. Both are dimensionless and use standard speed normalization T³, unlike the T⁵ printed in the Legato appendix; do not directly compare paper values. Pause, reset, missing identity and long gaps split segments. Verified expired-plan holds use the recorded constant command because scheduled can contain measured-state placeholders. Segment metrics are duration-weighted within each channel; episodes remain equally weighted. All exclusions are exported.

L / R Mean, P95, Max Continuous: old committed reference versus incoming first point at the incoming start time. End hold: verified held command versus incoming first point, reported separately. Mean/P95 use equal rollout weighting; Max is the global maximum. n is rollout count; b is boundary count.

Trajectory similarity Position RMSE, origin-aligned shape RMSE, endpoint error and velocity-direction cosine over the same future window.

MetricDefinition
M25 / M50 / M75 ↑Fraction of episodes with maximum predicted progress reaching 25% / 50% / 75%.

MP ↑Mean of per-episode maximum predicted progress.
PPL ↑Progress path efficiency: MP² / Σ|Δprogress|.
CRA ↓Mean regression below the running maximum progress, normalized by MP.
STR ↓Fraction of adjacent progress changes below the threshold.
DRR ↑Recovery after the largest regression, using only episodes with regression.
FNS ↑Proximity to success for failed episodes.
SQS ↑Overall quality of successful episodes, combining efficiency, regression and stagnation.
