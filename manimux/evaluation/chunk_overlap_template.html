指标定义与阅读方式

在同一绝对时间取旧参考 aᵢ 与新参考 bᵢ，经离线 FK 得到 TCP 的 XYZ（mm），eᵢ=bᵢ−aᵢ。时间域取真实交集，不外推、不把旧轨迹末点复制成 overlap。

  • MSE：meanᵢ,xyz(eᵢ²)，单位 mm²。首/尾点仅取交集两端；首/尾窗口取 ceil(fraction×N) 个点。距离 RMSE：√meanᵢ‖eᵢ‖² = √(3×MSE)；平均 error 为 meanᵢ‖eᵢ‖，单位 mm。
  • 运动方向 cosine：把两条速度序列 ΔXYZ/Δt 展开后求 cosine；接近 1 表示整体运动方向一致，负值提示方向相反。一侧 RMS 速度低于阈值时留空，不用 0 替代。cosine 不反映速度幅度，因此一起看 velocity RMSE。
  • Shape RMSE：各自减去起点后再比较，区分恒定偏移与形状改变。关节 MSE 单独以 rad² 报告，去掉最后的夹爪维，不与 XYZ MSE 混合。
  • 四个视图：Decoded full = canonical_raw 全交集；Decoded after switch = 从 incoming committed.start 起的 canonical 交集；Committed full = 提交参考的全交集；Committed fixed = 从切换时刻起的固定时长窗口，覆盖不足则缺失。
  • 切换 gap：旧 committed 在新 start 时刻的 FK，与新 committed 首点的距离。覆盖不足留空。该量独立于 overlap 窗口是否够长；指标表中有独立分母。
  • 坐标时钟：canonical 首点时间 = observation_time_ns + source_offset_steps×dt_ns；不重复加 first_action_offset。先插值关节，再做 FK。采样包含两个精确端点、均匀间距不超过 incoming dt。
